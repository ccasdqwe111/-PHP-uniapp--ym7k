# 餐饮点餐系统小程序PHP+uniapp -ym7k

获取源码：ym7k.com/17837/餐饮点餐系统小程序PHP+uniapp -ym7k


总部定价与门店定价双模式价格体系实现
连锁茶饮品牌在不同城市不同商圈租金和竞争环境差异巨大。一点点、奈雪、喜茶在核心商圈和社区门店定价策略往往不同。系统必须支持总部定价和门店定价两种模式：总部定价确保品牌价格体系统一，门店定价赋予门店灵活应对本地市场能力。

商品价格表采用“基础价格+门店价格覆盖”设计。总部商品库存标准价格base_price，门店商品关联表存门店实际售价store_price和是否启用独立定价price_mode。price_mode为总部定价时store_price自动同步base_price；为门店定价时store_price由门店在总部允许范围内自主设置。总部可设置价格浮动上下限防止恶意低价或高价。

总部管理员在后台批量设置商品基础价格，一键同步到所有选择总部定价的门店。门店店长登录独立后台后可查看本店商品列表，对启用门店定价的商品调整价格。调整时系统校验是否超出总部设定区间，超出则拒绝保存并提示。所有价格变更记录操作日志便于总部审计。

茶饮点餐对价格实时性要求高。系统使用Redis缓存商品价格，缓存键按门店ID和商品ID组合设计。总部修改基础价格后通过消息队列通知各门店缓存失效；门店修改价格后立即更新本店缓存。下单时后端从数据库读取最新价格校验，防止前端篡改。

优惠券、满减、第二件打折等营销活动与价格体系紧密相关。系统设计营销规则引擎支持活动价与门店定价叠加计算。总部统一活动优先于门店自主活动，门店活动需在总部允许范围内创建。支付时系统按优先级依次计算优惠确保价格计算准确。合理的价格模型、严格权限控制和高效缓存同步保障价格体系准确稳定。
